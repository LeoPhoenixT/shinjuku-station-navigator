# Security Policy

## Supported version

Security fixes are applied to the latest version on the default branch. This project does not currently maintain older release branches.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed credential. Use GitHub's **Report a vulnerability** option on the repository Security page to submit a private security advisory.

Include the affected component, reproduction steps, impact, and any suggested mitigation. Do not include real credentials or unnecessary personal data. You should receive an acknowledgement within seven days.

For ordinary bugs that do not have a security or privacy impact, open a normal GitHub issue.
